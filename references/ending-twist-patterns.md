# 三型结尾反转：判定树与做法

反转类型是选一，不是全上。选错型 = 全片气质错。

## 三型速览

| 类型 | 一句话 | 出圈概率 | 长尾传播 | 情绪落点 |
|---|---|---|---|---|
| 元反转 | 观众/玩家/作者进入画面 | ★★★★★ | ★★★☆ | 冷、后劲大 |
| 温柔反转 | 全球设定收进小人物的小愿望 | ★★★☆ | ★★★★★ | 暖、回味 |
| 笑点反转 | 一个滑稽细节泄压 | ★★★☆ | ★★☆ | 松弛 |

## 判定树

**问 1**：概念本身在讨论「观测/操控/媒介/程序」吗？
- 是 → **元反转**（概念的必然收束）。
- 否 → 继续问 2。

**问 2**：全片是否落在一个具体的人身上？
- 是 → **温柔反转**（把宇宙收回她/他的日常）。
- 否 → 继续问 3。

**问 3**：片长是否 < 2 分钟？或是否需要避免说教感？
- 是 → **笑点反转**。
- 否 → 回到问 2 重新考虑主角。

## 元反转：具体做法

**目标**：告诉观众你也在系统里。

**技法**：
1. **系统外镜头切入**：《箭头》最后镜头切到一台真实电脑，屏幕上正在玩一个 RTS 游戏。《城市上空的巨物》镜头缩小成剪辑软件界面，作者本人从转椅上回头。
2. **让系统内角色朝镜头说话**：《箭头》里蓝屏字幕 We need to talk 就是元反转的低成本版本。
3. **让作者/创作过程出现**：作者本人入镜、剪辑软件界面出现。

**做元反转的红线**：
- 不能只是「其实主角一直在做梦」→ 那是烂尾反转。
- 元反转必须把**观众本人**放进去，而不只是主角觉醒。
- 反转之后不要再解释，戛然而止。

## 温柔反转：具体做法

**目标**：把宇宙级设定收进一个普通人的小愿望。

**技法**：
1. **补一个小人物**：《绿幕》里的医生补心、老太太补视野、爸爸补一块煎蛋。《Planet Thief》里泰勒说「我决定偷走这颗星球」。
2. **让宇宙设定服务于日常感情**：不是「拯救世界」，而是「让我妈能再看见」「让我朋友能见到前任」「让我给女儿做一次真正的煎蛋」。
3. **收束旁白必须小**：「宇宙很大，生活更大。」「好不容易当一次人，我想按自己的意思使劲活。」

**做温柔反转的红线**：
- 不要煽情过头，一段就够。
- 不要给主角浓重的悲惨背景 → 反差在于「他就是普通人」。
- 温柔反转最忌讳道理说得太满 → 只给一句，剩下的留白。

## 笑点反转：具体做法

**目标**：用一个生活化滑稽细节泄压，避免说教感。

**技法**：
1. **反差细节**：《我不是外星人》里外星人费尽心思圆谎，最后败给「他给饺子挤番茄酱」。《绿幕》劫匪烧穿第一道金库门，「还有绿卡吗」「没了」。
2. **末位喜剧点**：把全片最好笑的一个梗留到最后 20 秒。
3. **不要嘴炮**：笑点最好由动作/画面完成，而不是靠角色说笑话。

**做笑点反转的红线**：
- 不要把笑点铺得太长 → 一到两个镜头解决。
- 不要用网络热梗 → 3 个月后就过期。
- 不要让笑点冲淡道德判据 → 判据要在拍 5 已经说完。

## 混合陷阱

想同时用两型反转的诱惑很大，几乎全部翻车：

- **元 + 温柔**：反转指向观众，又想催泪 → 情绪频道打架，观众感觉被玩弄。
- **温柔 + 笑点**：想收暖又想搞笑 → 两边都不到位，成了尴尬短剧。
- **元 + 笑点**：还可以偶尔混合（《垃圾站》里角色吐槽自己是 AI 生成的），但要克制。

**结论**：一型到底，不要贪心。
