# 六拍叙事结构：实操细节

本文档展开 SKILL.md 第 2 节的六拍公式。执行流程 B（脚本填充）时读它。

## 快速回顾

| 拍 | 时长占比 | 内容 |
|---|---|---|
| 1. 权威播报设定 | 5%–10% | 一句话讲完规则，不讲原理 |
| 2. 单点验证 | 10%–15% | 规则第一次落在具体小人物 |
| 3. 跨国蒙太奇扩散 | 20%–30% | 换国家/语言/视角，升级为全人类事件 |
| 4. 建制出场 | 15%–20% | 政府/军方介入，对策取好名字 |
| 5. 金句点题 | 3%–5% | 全片核心台词，留道德缺口 |
| 6. 反转 + 收束旁白 | 10%–15% | 反转指向观众，旁白把宇宙拉回日常 |

## 拍 1：权威播报设定

**目的**：让观众在 10 秒内接受一个荒诞规则。

**做法**：
- 新闻主播画面 + 台标 + 底部滚动字幕（英文最佳，如 TIC News Network Live / BREAKING NEWS）。
- 主播用平静语气一句话讲完规则。或者用冷静旁白替代主播，画面用航拍/城市空镜。
- **严禁**：解释原理、铺垫背景、闪回来源。规则「就是发生了」。

**常见陷阱**：
- 用长旁白铺垫世界观 → 用第一个新闻镜头替换。
- 让主播表现出震惊 → 平静反而更可信。
- 台标做得太假 → 直接借用真实新闻台的视觉语言（BBC/CNN/CCTV），改一个字母区分。

## 拍 2：单点验证

**目的**：把抽象规则落地到一个可共情的具体事件。

**做法**：
- 选一个「最典型的普通人」+「最日常的动作」：主妇拎菜、上班族刷卡、警察举枪、学生举手。
- 规则第一次生效必须是**具象且瞬间**的——一秒内看到结果。
- 配合一个路人视角的手机竖屏素材，越粗糙越可信。

**常见陷阱**：
- 让主角有对白 → 尽量不给台词，只给动作和反应。
- 用航拍视角 → 单点验证要用近景，观众要看清楚。

## 拍 3：跨国蒙太奇扩散

**目的**：把「一起事件」升级为「全人类事件」。

**做法**：一组 6–12 个短镜头，每个不超过 2 秒：
- **国家/城市多样**：至少涵盖亚洲/欧洲/美洲/非洲各一个可辨识地标。
- **视角多样**：竖屏手机、监控画面、直升机航拍、卫星图、社交媒体截图 UI、TikTok 界面。
- **天气/时间多样**：白天、深夜、雪地、沙漠、都市。
- **语言多样**：字幕条切换英语/西语/阿拉伯语/日语。

**推荐做法**：在这一拍里插一到两个「地标奇观」——乌鲁鲁升空、埃菲尔铁塔被黑布罩、时报广场变成 XX。这是最高性价比的传播物料。

**常见陷阱**：
- 全部都是同一个城市的不同角度 → 显得像小规模事件。
- 每个镜头超过 3 秒 → 节奏塌陷，观众划走。

## 拍 4：建制出场

**目的**：让规则的量级再升一档，同时提供官方话语的荒诞感。

**做法**：
- 白宫新闻发布会 / 联合国大厅 / 太空指挥中心。
- 官方给现象命名：「反牧羊人计划」「旧家具计划」「Shepherd the Shepherd」。这些名字**必须够正经、够拗口**，越像真政策越好笑。
- 加一段电视新闻的专家访谈条，姓名条写 Dr. XXX / Prof. XXX。

**为什么好听的名字重要**：观众会自己传播这个名字。「反牧羊人计划」是《糖果》评论区的高频词。

**常见陷阱**：
- 官方话语过于沉重 → 加一点荒诞感（用词过度正式，反而喜剧）。
- 让政府一开始就失败 → 官方要「看起来在应对」，反差才成立。

## 拍 5：金句点题

**目的**：给观众一句可以复制粘贴到弹幕、朋友圈、评论区的台词。

**做法**：
- 全片只放**一句**核心台词或旁白。多了就稀释。
- 只给判断，不给解释。「宇宙很大，生活更大。」「我们需要谈谈。」
- 把金句放在反转前一拍，用来蓄势。

**常见陷阱**：
- 想写好几句金句 → 全都不记得。
- 金句太抽象 → 具象化到「一个动词 + 一个宾语」。

## 拍 6：反转 + 收束旁白

**目的**：把观众从「看故事的人」变成「故事里的人」。

**做法**：
- 从三型反转（元/温柔/笑点）里选一型，详见 [ending-twist-patterns.md](ending-twist-patterns.md)。
- 反转镜头之后**必须有一句收束旁白**，把宇宙级设定拉回日常一句话。
- 长度控制在 15–30 秒。

**常见陷阱**：
- 反转是「其实是梦」→ 观众骂你。
- 反转之后还想再解释 → 别解释，戛然而止最有力。

## 时长与拍数的关系

| 目标片长 | 六拍要不要全用 | 建议 |
|---|---|---|
| 60 秒（试验期作品） | 保留 1/2/6，压掉 3/4/5 | 单点即扩散，一句金句就是收束 |
| 3 分钟 | 保留全部六拍，压缩 3/4 | 每拍最短 20 秒 |
| 7 分钟（爆款片长） | 全部六拍 + 分支案例 | 3 里加 2 个案例、6 里可留剧集钩子 |
| 10 分钟以上 | 用剧集化结构 | 参考《垃圾站》，改用固定场景 + 主角，六拍变成单集小结构 |

## 每拍的产出物模板

流程 B 里生成的脚本骨架用以下表头：

```
| 拍  | 时长        | 场景/镜头 | 画面描述           | 旁白/台词/字幕      | 画面内英文标示     | 视觉锚点 | 备注 |
|-----|-------------|-----------|--------------------|---------------------|--------------------|----------|------|
| 1   | 00:00–00:30 | ...       | 平静新闻主播镜头   | "今日全球出现……"    | BREAKING / LIVE    | 台标     |      |
| 2   | 00:30–01:00 | ...       | ...                | ...                 | ...                | ...      | ...  |
```

「视觉锚点」列是本 Skill 的关键——它保证同一个符号（气球头、糖果堆、光标）反复出现，替代角色一致性。
