# 14 部参考作品拆解

按发布顺序排列，每条给出：设定 / 结构 / 反转类型 / 视觉关键 / 可复用要素。用于流程 A/B/C 里给用户找对标作品。

## 试验期（2025.6–2025.11）

### 1. 城市上空的巨物（2025-06-09，1:34，16.9 万播放）
- **设定**：全球上空漂浮巨型未知物一年。
- **结构**：新闻/采访/游行/自拍/政府声明层层堆真。
- **反转类型**：元反转（画面缩小成一台电脑的剪辑界面，作者本人回头）。
- **视觉关键**：伪纪录片语法奠基之作。
- **可复用**：拍 1 权威播报的教科书写法。

### 2. AI MV 我自己待着就能乐（2025-06-24，1:04，6.9 万播放）
- **设定**：向日葵笑脸气球替换所有人的头（社畜、囚犯、宇航员、教室女生）。
- **结构**：跨场景符号一致性验证。
- **反转类型**：温柔（天台女生摘下气球，露出一张毫无表情的真脸）。
- **视觉关键**：**符号替代角色一致性的最纯粹示范**。
- **可复用**：想做 MV/群像时的首选参考。

### 3. Green Screen 绿幕（2025-07-15，2:16，192.7 万播放，试验期唯一爆款）
- **设定**：全球飘下绿色卡片，可以替换掉与卡片同等大小（约 90 平方厘米）的任意现实。
- **结构**：设定 → 温情案例（补心/补视野/补煎蛋）→ 喜剧彩蛋（劫匪烧金库）。
- **反转类型**：温柔 + 笑点（罕见有效混合，因片长足够）。
- **视觉关键**：绿卡是本片的视觉锚点。
- **可复用**：想做 2 分钟级别的温情高概念时的模板。

### 4. Planet Thief 行星小偷（2025-07-31，4:34，6.5 万播放）
- **设定**：2045 年地球联邦把 X17F 行星当储物箱，泰勒是唯一的跨行星储物管理员。
- **结构**：日志体独白。
- **反转类型**：温柔（我决定偷走这颗星球）。
- **视觉关键**：单人独白 + 星球外景，一致性压力低。
- **可复用**：低预算高情绪的独白片模板。

### 5. I am not an Alien 我不是外星人（2025-08-28，3:09，11.6 万播放）
- **设定**：审讯室里，外星人用一连串生活化谎言解释异常。
- **结构**：全片一个审讯室、两个角色、双人静态戏。
- **反转类型**：笑点（他给饺子挤番茄酱，当场暴露）。
- **视觉关键**：**静态双人戏处理长台词的最佳示范**。
- **可复用**：想做多台词短片时的场景模板。

### 6. 黑屋（2025-09-12，2:51，17.6 万播放）
- **设定**：改编陈楸帆《赢家圣地》，关闭感官进入虚拟世界。
- **结构**：访谈式独白 + 逐层解构。
- **反转类型**：元（主持人的头变成一个充气的 D 字母）。
- **视觉关键**：访谈间静态场景 + 一个荒诞视觉锚（充气 D）。
- **可复用**：改编文学 IP 时的极简做法。

### 7. 世界要毁灭了，我跑去找前任（2025-10-03，1:20，5.5 万播放）
- **设定**：末日倒计时一小时的群像小品。
- **结构**：极短快切，每个人一个荒诞反应。
- **反转类型**：笑点（囚犯高喊我自由啦）。
- **视觉关键**：Sora 2 试水，验证快速批量生成能力。
- **可复用**：60–90 秒群像喜剧模板。

### 8. Kick! 最慢的一颗进球（2025-10-31，1:02，8.9 万播放）
- **设定**：一颗蹴鞠球穿越人类历史。
- **结构**：物体守恒 + 匹配剪辑。
- **反转类型**：温柔（穿越所有文明后完成进球）。
- **视觉关键**：**物体守恒 + 跨时代匹配剪辑**（每镜 <2 秒，一致性只维持一个球体形状）。
- **可复用**：想做时间跨度大的短片时的模板。

### 9. Alt Tab 她没成为的自己（2025-11-03，1:01，39.6 万播放）
- **设定**：分屏对齐一个女性的普通一天与她「没成为的自己」。
- **结构**：匹配剪辑 + 分屏。
- **反转类型**：温柔（她仍趴在工位，嘴边留着面包屑）。
- **视觉关键**：分屏匹配剪辑，AI 一致性压力被拆到最小单元。
- **可复用**：想做「命运分支」题材时的模板。

## 爆发期（2025.12 起）

### 10. 箭头（2025-12-05，7:11，780.4 万播放）
- **设定**：天空出现巨大鼠标箭头，像玩家一样点击、复制、删除现实。
- **结构**：完整六拍 + 元反转结尾。
- **反转类型**：元（切到一台电脑，玩家把游戏里的小兵删掉）。
- **视觉关键**：右键菜单 UI + 蓝屏 + 城市改写。**低生成难度、极高传播力**。
- **可复用**：**六拍公式的教科书**。想做模拟宇宙/程序寓言时的首选参考。

### 11. 牌子（2026-02-03，7:45，2122.8 万播放，149 万赞，全站顶流）
- **设定**：世界各地凭空长出无法解释的路牌，且每一块都「说到做到」。
- **结构**：完整六拍 + 元反转 + 语言层面升级（巴别塔、三不猴）。
- **反转类型**：元（三不猴牌让全人类失语）。
- **视觉关键**：路牌是视觉锚点，全片可复用。
- **可复用**：**惩罚人类好奇心的模板**。评论区代入感最强的一种母题。

### 12. 网站（2026-04-12，11:16，573.8 万播放）
- **设定**：elsewherenews.com 播报别处新闻，观看数超过阈值就成真。
- **结构**：六拍 + 案例堆叠 + 元反转钻进细胞。
- **反转类型**：元（观测机制深入生命本源）。
- **视觉关键**：网页 UI + 灭绝动物回归 + 地标黑布罩。
- **可复用**：想做媒介/观测类概念时的模板。

### 13. 垃圾站 EP01（2026-07-10，11:53，1081.9 万播放）
- **设定**：垃圾发电厂夜班工人发现非人生命寄宿在垃圾里。
- **结构**：固定场景 + 固定主角，剧集化尝试。
- **反转类型**：钩子式收束（黑影生物出现，留续集）。
- **视觉关键**：贴纸质感黄色小人 OR + 陶瓷假人 + 银液体猫。**符号锚点极强**。
- **可复用**：**想把爆款方法论转成剧集时的唯一参考**。

### 14. 糖果（2026-09-10，8:59，377.8 万播放）
- **设定**：人类即将迈入一级文明，土卫十八「潘」降下规则：伤人者变糖果。
- **结构**：完整六拍 + 温柔反转 + 建制出场（反牧羊人计划）。
- **反转类型**：温柔（宇宙很大，生活更大）。
- **视觉关键**：糖果堆是视觉锚点；蚂蚁把糖果搬成马蒂斯《舞蹈》的镜头是全片记忆点。
- **可复用**：想做「文明入场资格审查」类主题时的模板。

## 播放量分布参考

试验期（前 9 部）平均 41 万播放，爆发期（后 5 部）平均 987 万播放。分水岭事件：**片长从 1–4 分钟跳到 7–12 分钟 + 标题从英文概念词换成两字中文名词 + 内容从「展示一个奇观」升级到「推演一条世界级规则」**。这三个变量同时变，是本方法论最重要的经验教训。
