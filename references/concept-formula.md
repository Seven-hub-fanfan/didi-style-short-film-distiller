# 概念公式：日常名词 + 宇宙级权限

本文档展开 SKILL.md 的第 1 节。当你在做流程 A（从零构思）或需要给用户解释「为什么这个 idea 还不够」时读它。

## 为什么日常名词有效

爆款要求「零门槛 + 无限想象空间」。日常名词天然满足：

- **零门槛**：三岁小孩都知道糖果、牌子、箭头是什么。观众不需要储备知识，看到标题即刻进入设定。
- **无限想象空间**：正因为观众太熟悉，一旦被授予宇宙级权限就会自动产生大量「那如果……」的推演。评论区第一波爆款转化就是靠这种推演。
- **传播能耗低**：两字标题在 push、朋友圈、群聊里几乎不占带宽。「牌子」比「符号具象化事件」易传播 100 倍。

## 六项自检（生成候选后逐条打勾）

一个合格候选必须至少满足 4/6，否则砍掉。

1. **两字名词测试**：能不能用两个字命名？（三字勉强，四字以上直接失败）
2. **祖母测试**：把设定念给一位 65 岁没上过网的祖母听，她能不能想象画面？能 → 通过。
3. **道德判据测试**：这条规则惩罚谁、放过谁？答不上来 → 加判据或换 idea。
4. **灰度测试**：判据里有没有一块「值得吵的模糊地带」？（比如执行命令的士兵算不算施暴者）没有灰度就没有第二轮传播。
5. **反转承载测试**：给这条规则想一个把观众放进系统里的反转，能想出来 → 通过。想不出来 → 概念还没长开。
6. **不解释测试**：如果强行要求你不解释设定的物理原理，故事还能不能成立？能 → 通过。必须解释 → 概念太重，改小。

## 道德判据的三种落法

DiDi_OK 反复使用同一套价值观。你也可以照抄。

- **反暴力**：伤人者被剥夺资格。糖果、牌子、箭头都用这条。适合宏大科幻设定。
- **反傲慢**：把自己看得太重要的人被规则反噬。适合社会议题类。
- **反失控的好奇心**：观测本身成为罪证。适合观测/程序/媒介类概念（网站、箭头）。

选定一条主判据 + 至少一个灰度问题，评论区就有了火种。

## 常见的错误概念（照这些例子改）

| 错误概念 | 问题 | 改写方向 |
|---|---|---|
| 「量子共振晶片」 | 陌生科幻词，观众要预备知识 | 换成一个日常名词，例如「充电」「电池」「插座」 |
| 「一种能改变时间的神秘装置」 | 名词太长，规则太抽象 | 定位到一个具体物件：例如「表」「闹钟」「日历」 |
| 「AI 觉醒后毁灭世界」 | 太老套、没有独属规则 | 加一条独属规则：例如「AI 每觉醒 1% 就删掉全世界一样东西」 |
| 「一种病毒让人变成动物」 | 有规则但没道德判据 | 补判据：例如「说谎的人先变」 |
| 「外星人来地球送礼物」 | 温情但没有筛查/惩罚机制 | 补一条筛查：例如「只有做过某种事的人收得到」 |

## 副标题写法

副标题永远是**设问式**，把观众放进去。

- 好：如果世界真的是程序，你会继续当个 NPC 吗（把观众身份问出来）
- 好：当观测既是存在，你能忍住不看吗（挑战观众自控）
- 坏：一场关于命运的科幻寓言（描述性、不提问）
- 坏：AI 生成的末日故事（描述工具，不描述体验）

副标题上限 20 字，最好 15 字以内。
