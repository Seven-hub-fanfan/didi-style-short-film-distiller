# 视觉语言与 AI 工具选型

DiDi_OK 之所以能在 AI 视频普遍崩坏的年代做出可看的爆款，关键在于**用视觉语法规避 AI 的短板**。这份文档是所有拍摄/生成决策的checklist。

## 视觉语法五律

### 律 1：伪纪录片是母语

**做法组合**：
- 新闻台标 + BREAKING / LIVE / URGENT 底部字幕条
- 受访者姓名条：Dr. XXX / Prof. YYY / Officer ZZZ / John Smith, Local Resident
- 直升机航拍 + 手机竖屏 + 监控摄像头 + 卫星图轮换
- 英文界面（新闻/系统 UI）+ 中文字幕（观众母语）

**为什么这么重要**：这套语法同时让荒诞设定「像真的」，又用低码率、噪点、抖动**掩盖 AI 生成的形变**。这是本方法论最不可替换的一招。

### 律 2：1–2 秒快切

**做法**：绝大多数镜头 1–2 秒切走，只在极关键的反转或金句拍留 3–5 秒。

**为什么**：AI 生成的每一帧都有可能崩，快切让观众来不及看清。慢镜头 = 送分给崩坏。

### 律 3：一致性靠符号不靠角色

**AI 现状**：跨镜头保持同一张脸非常困难。

**替代方案**（按性价比排序）：
1. **道具替代脸**：AI MV 用向日葵气球头代替人脸；《垃圾站》用贴纸风黄色小人 OR；《箭头》用一枚天空光标。
2. **同款制服**：让角色一直穿同一套显眼衣服（黄背心、红围巾、白大褂）。
3. **同款姿态/动作**：让角色反复做同一个手势。
4. **只保留背影/侧影**：不给正脸就不用担心一致性。

### 律 4：长台词压进静态双人戏

**为什么**：AI 生成边走边说 = 灾难。口型、走位、眼神全崩。

**替代方案**：
- **审讯室**（《我不是外星人》）：两个人坐着，一张桌子，两把椅子。
- **访谈间**（《黑屋》）：一把椅子对着摄像机，中景固定。
- **电视新闻主播**：半身构图，只需要嘴动即可。

### 律 5：奇观清单收敛

DiDi_OK 反复复用的奇观模板（性价比最高，可直接抄）：

| 模板 | 示例 | AI 生成难度 | 观众记忆点 |
|---|---|---|---|
| 天空巨物 | 巨型糖果土星、悬浮怪物、光标 | 中 | 极高 |
| 日常空间的荒诞生物 | 地铁奶牛、开校车的哈士奇、街头骑单车的熊 | 低 | 高 |
| 被改写的世界地标 | 乌鲁鲁升空、埃菲尔铁塔黑布罩、时报广场变异 | 中 | 极高 |
| 全球同步现象 | 全球蓝屏、全球下雪、全球突然停电 | 低 | 高 |
| 系统 UI 覆盖现实 | 右键菜单、蓝屏对话框、加载条 | 极低 | 中 |

DiDi_OK 自述工具（作为参考基线）：

| 作品 | 主要工具 | 用途 |

| 箭头 | Nano Banana + VEO3 + Runway | 出图定形 / 主镜生成 / 补镜头 |

| Kick! | Google Veo 3.1 + Suno | 跨时代匹配剪辑 |

### 各拍推荐工具

| 拍 | 推荐工具 | 关键点 |
|---|---|---|
| 拍 1 权威播报 | VEO3 / Sora（静态主播镜头）+ 后期加台标字幕条 | 主播 3 秒静态镜头，AI 生成压力最小 |
| 拍 2 单点验证 | Runway / Kling（一致性 image-to-video） | 一张 key frame + 短运动，配合手机竖屏噪点 |
| 拍 3 跨国蒙太奇 | VEO3 / Sora 快速批量生成 + Nano Banana 补关键帧 | 每镜 1–2 秒，不追求一致性，追求多样性 |
| 拍 4 建制出场 | VEO3（会议室、发布厅） + 拟真新闻剪辑 | 静态、双人为主 |
| 拍 5 金句点题 | 素材复用即可，不需要新生成 | 关键在字幕字体和收音 |
| 拍 6 反转 | 元反转：After Effects 合成剪辑软件界面；温柔/笑点反转：Runway/VEO3 | 关键帧要仔细精修 |

### 配乐

- **Suno** 是 DiDi_OK 明确使用的配乐工具，长片可以定制主旋律。
- 别用免版权的通用 BGM，会让全片降一档。
- 关键节奏点（拍 3 结尾、拍 6 反转）要有音乐重击。

## 后期与字幕

- **字幕字体**：新闻风格用无衬线字体（Helvetica / Arial / 苹方），电影感用衬线体（宋体粗体）。
- **英文与中文并存**：画面内 UI 用英文（Breaking / Live / Danger / We need to talk），中文字幕作观众母语层。
- **色调**：灾难片青橙对比 + 胶片颗粒（可用 Lut 一键出）。
- **画幅**：主片 16:9；蒙太奇里可以插竖屏（正好模拟手机素材）。

## 声明合规

DiDi_OK 全部作品明确挂「含 AI 生成内容」标识。B 站/抖音/YouTube 都建议照做——不假装实拍反而是加分项，因为观众欣赏的正是「AI 才能做的片子」。

## 反面清单（视觉部分）

- 不要长镜头炫技（>5 秒的连续镜头基本会崩）。
- 不要角色边走边大段说话。
- 不要给正脸特写，除非确认一致性可靠。
- 不要用通用 BGM。
- 不要用低质量的字幕字体。
- 不要试图掩盖 AI 生成的事实——观众看得出来，坦白反而加分。
